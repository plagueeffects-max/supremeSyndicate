# Supreme Syndicate

Supreme Syndicate is a premium medical services website featuring a high-end, Awwwards-caliber digital presence. 

## Features
- **Modern UI/UX**: Dark-themed, sophisticated design with glassmorphism and premium typography.
- **Dynamic Hero Section**: Interactive 3D floating assets and seamless video backgrounds.
- **Smooth Animations**: GSAP and ScrollTrigger powered animations for an immersive experience.
- **Responsive Stacking**: Custom mobile card stacking logic for a professional touch.
- **Smooth Scrolling**: Lenis smooth scroll integration.

## Technologies Used
- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6+)
- GSAP (GreenSock Animation Platform)
- ScrollTrigger
- Lenis Smooth Scroll

## Getting Started
To view the project locally:
1. Clone the repository.
2. Open `index.html` in your browser (using a local server like Live Server is recommended for full feature support).

## Deployment
The site is optimized for performance and production-ready.
